# Image Listening

- `src/app/page.js`: rightmost Listening tab; native horizontal tab scroll. `ListeningImage` stays mounted while hidden so tab switching does not discard work. Existing vocabulary `Listening.js` and `/api/listening` behavior unchanged.
- `src/app/ListeningImage.js`: independent crop, staged `/api/upload`, server-confirmed size/ID, confirmation/deferral/retry, image background polling, cached lesson restore, sequential sentence TTS, browser-measured MP3 duration, sentence highlight/seek, playback speed, TXT/LRC/MP3 downloads.
- `src/app/api/listening-image/route.js`: POST `{imageId}` gives 202 `{jobId,status}`. GET `?jobId=` gives status/stage and `listening-image` transcript. Owner-bound HttpOnly `vocab_sid`, same-owner/image deduplication, 2 running listening jobs maximum, 2-hour retained result/status lifetime. Strict ID, actual image magic, size and generated transcript checks. Native `after()`, process-global jobs: restart loses pending work; completed lessons merge into 24-hour disk session cache. Pending ID stored in sessionStorage; shared poll helper resumes same-tab reload. Failed jobs clear pending ID and may be recreated explicitly with same staged image. Image expiry requires upload again.
- `src/lib/listening/transcript.js`: bounded bilingual sentence schema, measured cumulative LRC, ID3v2.4 UTF-8 USLT lyrics, removal of leading/trailing ID3 tags before MP3 frame concatenation. No generated timing estimates.
- `src/app/api/session/storage.js`: `DELETE ?type=listening` clears only Listening result/preview.

Images are paraphrased faithfully, not exact textbook transcription; model fidelity still needs real image review. Audio generated one sentence per call via existing `/api/listening` speech branch. Successful clips retained on failed TTS retry; audio blobs stay in browser memory, not disk session. Reload retains text/image but regenerates audio on demand. Playback uses sentence clips; individual clip controls seek within current sentence and clicking transcript selects/restarts a sentence. Combined downloaded MP3 may have encoder padding/gaps and player duration quirks; no sample-perfect gapless promise. Embedded USLT is unsynchronized bilingual lyrics, while separate LRC uses measured clip boundaries at 1×. Compatible player required to display lyrics. Background playback/automatic next sentence while screen locked depends on browser; test on target device. No new dependency, service configuration or credential persistence.

Checks: `node check-listening.mjs`, plus existing `check-errors.cjs`, `check-contrast-tip.cjs`, `check-lessons.mjs`, `check-pipeline.mjs`. Listening check injects AI transport and covers schema, LRC, USLT round-trip, legacy Listening presence, horizontal tab order, invalid/missing images, owner isolation, deduplication, completion/cache patch and failed-job status. Build from `/root/.openclaw/workspace/vocab-app-next` after copying all `src/.`; only one build at a time. Actual image/TTS inference, authenticated crop/touch/mobile scroll, download/player compatibility and screen-lock playback require live/browser verification.
